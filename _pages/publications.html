01

Recursive self-improvement

MILO · Automated harness discovery via orchestrated multi-agent evolution

Paper ↗ Project page ↗

An agent is a model plus a harness: the prompts, tools, memory and control flow around it. MILO searches for better harnesses with islands that evolve in parallel, and an orchestrator agent that watches the whole search, diagnoses stalls and intervenes.

Results

  • State-of-the-art on Terminal-Bench 2.1, PaperBench and DeepSWE, against 8 expert-designed harnesses and 6 search methods given the same seeds and a 72-hour budget.
  • With gpt-oss-120b it lifts DeepSWE pass rate to 15.6%, 20× its initial harness, while prior search stays below 1%.
  • On Terminal-Bench every island stalls for nine rounds; the orchestrator’s interventions lift the best pass rate from 45.0% to 59.9% at the lowest token cost of any method. Evolved harnesses also transfer to Frontier-Bench without further search.

02

Test-time scaling

Hermes · Learning contextual reasoning unlocks test-time scaling

Paper ↗ Project page ↗

Spreading test-time compute over many context windows means deciding what each fresh context should do and what it hands back. Hermes leaves those decisions to the model, and Hermes-Learn (SFT, then RL) teaches a 4B model to make them. Below, Qwen3-4B after Hermes-Learn works through AIME 2026, problem 4.

Results

  • Untrained, Qwen3-4B gets worse with Hermes: 37.1% → 16.2% on 238 AIME and HMMT problems.
  • After Hermes-Learn it reaches 47.3%, beating one 56K-token context with the same total budget (41.8%), and it beats that baseline on all four math benchmarks.
  • It generalizes: deeper delegation than in training reaches 55.6%, Hermes lifts other test-time scaling methods (DeepSeekMath Agent 15.1% → 52.5%), and the recipe transfers to Olmo-3-7B (4.8% → 40.6%).

03

On-policy distillation

SCOUT · On the off-policy teacher in on-policy distillation

Paper ↗ Project page ↗

In on-policy distillation the student writes the response and a stronger teacher scores every token. But the teacher was trained to continue its own reasoning, and the deeper into a student’s response it reads, the worse it does. SCOUT trains the teacher to continue student-written prefixes.

Results

  • The problem is measurable: the teacher’s accuracy falls from 47.5% to 30.2% as it continues longer student prefixes (AIME 2025).
  • SCOUT gives the best distilled student in all four settings: +2.2 points over OPD on math and +3.1 on code (Qwen3-4B → 1.7B), +2.6 with an RL-trained 8B teacher, and +1.2 across model families (Skywork-7B → DeepSeek-1.5B).
  • It stacks with other OPD improvements: added to OPTR, it gains another 2.5 points on math.
